# packages/templates (placeholder)
Year-versioned template profiles for **T** (AICTE template) and **P** (portal-generated) documents: the portal affidavit (Affidavit 2, 24 declarations, land table, 4 room tables), Formats 1–3, Affidavits 3/4/8/9/10, Certificates 1–3, Deficiency Report, Application Report, EoA/LoA letters (design v2.2.1 B1, C3, D4).

- Built in the **M3 slice** (P-2) and used by M5 (P-3). Not implemented in slice 0.
- Every profile is keyed by template year ("APPROVAL PROCESS YYYY-YY" + heading word) and records `template_id` so results can be replayed (Portal spec §2.12).
- Profiles describe layouts only. **Synthetic values only**; never copy text or values from a real document into this folder.
